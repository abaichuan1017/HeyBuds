# 兼容性与证据边界

记录日期：2026-10-17，Asia/Shanghai。

## 三种证据

1. **源码适配**：已移植协议逻辑并导入型号配置，不代表实际设备能连接。
2. **协议测试通过**：实际执行了对应解析器或模拟会话测试。配置能解析仅证明配置兼容，不能代替该型号全部指令的验证。
3. **实机通过**：必须记录具体设备、功能、操作及实际结果。未观察到的项目保留“待验证”。

## 实机检查清单

| 项目 | 验收方法 |
| --- | --- |
| 连接／身份 | 打开控制服务，读取产品 ID，核对型号 |
| 电量 | 读取三路数据，验证未知槽位与状态刷新 |
| 降噪 | 切换可用模式，读取一致状态；听感另行确认 |
| EQ／空间音频 | 写入后回读一致；不将通用 ACK 当成功 |
| 手机同步 | 手机修改后观察 Mac 状态变化 |
| 入盒／重连 | 入盒、取出后观察清空与恢复 |
| 睡眠／唤醒 | 用户正常睡眠与唤醒后观察恢复 |
| 多设备 | 在真实远端设备上核对列表与连接状态 |

实机过程中不自动解除配对，不访问 OTA，不替用户切换整机睡眠。
