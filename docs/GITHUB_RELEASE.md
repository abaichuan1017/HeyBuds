# HeyBuds v0.3.0

首次以 **HeyBuds** 名称整理的开源版本，原项目名为 EncoBar。

- 应用、工程模块、资源、诊断工具统一改名。
- 保持现有 macOS 原生布局与六类品牌后端。
- 一次性迁移旧版已识别的偏好，保留已有 HeyBuds 设置。
- 提供中英文说明、GPL-3.0-or-later 许可、第三方署名、贡献指南与构建工作流。

要求 Apple Silicon、macOS 27 或更新版本。下载应用包 `HeyBuds-arm64.zip`，源码包为 `HeyBuds-v0.3.0-source.zip`，校验值见 `SHA256SUMS`。

本地原工程与独立解压的源码包均通过 64 项测试；应用采用 ad-hoc 签名，未公证。目录导入不代表逐款实机兼容，新增品牌实机验证仍待完成。当前 GitHub CI 尚无运行结果，发布后请核对 Actions 状态。

仓库简介可使用：

> Native macOS menu bar companion for multi-brand earbuds. Battery, noise control, sound settings and connected hosts, with read-only AirPods / Beats status.

建议仓库名：`HeyBuds`。可用主题：`macos`、`swift`、`swiftui`、`bluetooth`、`earbuds`、`menu-bar`。
